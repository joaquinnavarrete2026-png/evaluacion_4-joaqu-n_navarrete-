# Evaluación Nº4 — Proyecto Integrado Final (PIF) | Desarrollo de Frontend

Portafolio web profesional migrado y mejorado desde HTML/CSS plano a una aplicación moderna de una sola página (SPA) utilizando **React, Vite, TypeScript, React Router** y metodología **CSS BEM**.

## 🚀 Tecnologías y Stack
* **React 18** + **Vite** (Entorno de desarrollo ultrarrápido).
* **TypeScript** (Tipado estricto sin uso de `any`).
* **React Router DOM v6** (Enrutamiento SPA multipágina).
* **GitHub REST API** (Consumo asíncrono en tiempo real con `AbortController`).
* **CSS Modules / BEM** (Metodología de bloques, elementos y modificadores).

## 🛠️ Instalación y Ejecución local

Sigue estos pasos para clonar y levantar el proyecto en tu equipo:

1. Clona este repositorio:
   ```bash
   git clone [https://github.com/joaquinnavarrete2026-png/evaluacion_4-joaqu-n_navarrete-.git](https://github.com/joaquinnavarrete2026-png/evaluacion_4-joaqu-n_navarrete-.git)

2. Instala las dependencias:
   ```bash
   cd evaluacion_4-joaqu-n_navarrete-
   npm install
   ```

3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Abre tu navegador y visita `http://localhost:5173` para ver la aplicación en funcionamiento.
